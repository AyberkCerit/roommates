# RoomMates

RoomMates, ortak çalışma, video izleme ve mülakat çalışması odaları kuran bir Spring Boot REST API'sidir (Spring Boot 4.1.2, Java 25, MySQL, Spring Data olmadan elle yazılmış repository'ler). Sunucu Uygulama ve Geliştirme dersi vize projesidir.

**Durum:** iskelet
